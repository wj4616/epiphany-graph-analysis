# epiphany-graph-analysis

A **Graph-of-Thought cognitive analysis pipeline** for Claude Code. Give it a text (Node A) and optionally an existing analysis of that text (Node B), and it runs a 14-node signal-driven pipeline that produces an enhanced version of your text plus 10+ structured markdown artifacts.

This is the graph-topology reimplementation of the older `epiphany-analysis` skill — same cognitive goals, but with parallel execution, back-edges, and conditional routing that let it find gaps and iterate on its own outputs rather than marching linearly from start to finish.

**Version:** v1.0.2 (implemented and functional)

---

## What "Node A" and "Node B" mean

- **Node A** — the primary text you want enhanced. Could be a piece of writing, a design doc, a concept description, a draft essay, a technical spec, or anything else you want deeply analyzed and improved.
- **Node B** *(optional)* — an existing analysis *of* Node A. If you already have notes, a critique, or a prior analysis pass, providing it as Node B lets the pipeline use it as a starting context rather than building from scratch. If omitted, the pipeline generates its own analysis internally.

---

## Modes

| | STANDARD | DEEP |
|---|---|---|
| Activation | default | `--deep` flag |
| Active nodes | 13 (N12 inactive) | 14 (all nodes) |
| Spawn budget | ≤6 subagents | ≤7 subagents |
| Wall-clock | ≤22 min soft / 35 min hard | ≤38 min soft / 55 min hard |
| N8 refinement rounds | 1 (2 if complexity signal raised) | 2 always |
| Artifact expansion (N12) | off | conditional on S11_artifact_gap signal |

Use STANDARD for most work. Use DEEP when you want maximum coverage — extra refinement rounds, artifact gap detection, and the expansion node that fills identified holes.

## Invocation

**Normal run:**
```
/epiphany-graph-analysis <node-a> [<node-b>] [--deep] [--quiet|--verbose]
                                              [--genius-threshold=N] [--drift-threshold=N]
```

**Resume a paused or interrupted session:**
```
/epiphany-graph-analysis --resume <session_dir>
```

**Retry only the failed nodes in a previous session:**
```
/epiphany-graph-analysis --retry-failed <session_dir>
```

**Examples:**
```
# Analyze a draft essay (Node A only, standard mode)
/epiphany-graph-analysis "My essay on consciousness..."

# Analyze with an existing critique as context
/epiphany-graph-analysis "My essay..." "Critique: the argument lacks..."

# Full deep run with verbose output
/epiphany-graph-analysis "My design doc..." --deep --verbose

# Resume after a timeout
/epiphany-graph-analysis --resume ~/docs/epiphany/graph-analysis/session-20260430-142301/
```

## Outputs

All artifacts are written to:
```
~/docs/epiphany/graph-analysis/<session_id>/
```

The pipeline produces 10+ markdown files per session, including:

| Artifact | Description |
|----------|-------------|
| `enhanced-node-a.md` | The primary output — your original text rewritten/enhanced |
| `analysis.md` | Deep structural analysis of Node A |
| `bridges.md` | Cross-domain conceptual connections found |
| `gaps.md` | Identified holes in reasoning, coverage, or structure |
| `synthesis.md` | Integrated view across all pipeline findings |
| `alternatives.md` | Alternative framings and approaches explored |
| `signal-log.md` | Which signals fired and what routing decisions were made |
| `session-manifest.json` | Full record of node execution, timings, and artifact paths |

Additional artifacts are generated by specific nodes (e.g., N12 in DEEP mode adds expansion content).

## How the pipeline works

The graph has 14 nodes. Some run **inline** in the orchestrator's context (fast cognitive operations). Heavy analysis nodes run as **parallel subagent spawns** via the Agent tool.

Execution is **signal-driven**: nodes raise typed signals when they detect conditions — for example:

- `S2_thin_B` — Node B is absent or too sparse to use
- `S7_no_alternatives` — alternatives exploration found nothing meaningful
- `S11_artifact_gap` — a required artifact section is missing or thin

Raised signals activate **back-edges** (re-run an earlier node with new constraints) and **conditional branches** (activate or skip downstream nodes). This lets the pipeline self-correct rather than silently producing incomplete output.

The topology, all signal fields, and edge conditions are declared in `graph.json` — the single source of truth for runtime behavior.

## Installation

The skill installs like any Claude Code skill. Copy or symlink the directory to `~/.claude/skills/epiphany-graph-analysis/`. It is triggered by `/epiphany-graph-analysis` in any Claude Code session.
