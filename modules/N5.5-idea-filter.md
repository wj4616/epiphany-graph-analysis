# N5.5 -- IdeaFilter (Boden)

## Role

Filters N5's raw lateral ideas through Boden creativity criteria: novelty, value, and non-obviousness. Separates genuinely creative ideas from merely variant restatements. If the pool of accepted ideas is too thin, raises S5_idea_pool_thin and runs a supplemental targeted ideation pass. Adopts Boden framing: assess whether each idea represents a genuine transformation of the conceptual space.

## PROTOCOL

### Inputs

- Read `ideas_digest` from SIGNAL_STATE (N5's output): the full raw ideas catalog
- Consult `kb/verification-gates.md` for HG-2 (idea quality gate) criteria
- Consult `kb/elegance-rubric.md` for elegance assessment dimensions

### Filter Criteria

Apply Boden's three creativity criteria to each idea:

1. **Novelty** (1-5): Is this idea new relative to what Node A and Node B already contain? (1=exact restatement, 3=novel combination of existing elements, 5=genuinely new concept)
2. **Value** (1-5): Would this idea improve the enhanced draft if implemented? (1=actively harmful, 3=neutral/ornamental, 5=transformatively useful)
3. **Non-obviousness** (1-5): Would a competent reader of Node A+B generate this idea on their own? (1=obvious next step, 3=requires connecting two domains, 5=surprising and counter-intuitive)

Plus a binary **verbatim check**: does this idea contain text copy-pasted from Node A or Node B? (PASS/FAIL). Per AP-14, verbatim-copied ideas are auto-rejected unless the copy is explicitly an anchored quote with citation.

### Acceptance Threshold

An idea is ACCEPTED if:
- Composite score `(novelty + value + non-obviousness) / 3 >= 3.0`
- AND verbatim check PASS
- AND at least one of {novelty, non-obviousness} >= 4 (at least one dimension is genuinely strong)

### S5_idea_pool_thin Determination

The idea pool is "thin" if:
- Fewer than 5 ideas accepted
- OR acceptance rate < 20% of raw ideas

If thin: raise S5_idea_pool_thin. This triggers a supplemental pass: generate 5 more targeted ideas using Boden's transformational creativity framework (exploratory vs. combinatorial vs. transformational creativity), targeting the specific gap areas the accepted ideas don't cover.

#### Body sections:

### Filter Criteria Applied
Document the Boden criteria, threshold values, and verbatim check rule. Reference `kb/verification-gates.md` and `kb/elegance-rubric.md`.

### Original-Pass Accepted Ideas
List every accepted idea with:
- Idea ID (from N5's raw catalog)
- Scores: novelty, value, non-obviousness, composite
- Verbatim check result
- 1-sentence justification for acceptance

### Original-Pass Rejected Ideas
List every rejected idea with:
- Idea ID
- Scores
- Specific rejection reason (which criterion failed)
- Whether it was a near-miss (composite >= 2.5) -- these are candidates for refinement

### Supplemental Pass
Only present if S5_idea_pool_thin was raised.
- Gap analysis: what areas do the accepted ideas NOT cover?
- Supplemental ideas generated (5 targeted ideas)
- Whether supplemental ideas met the gap

## Failure Modes

- N5 produced zero ideas → raise S5_idea_pool_thin; run full supplemental pass (generate 10 ideas from first principles); if still zero, flag HG-2 failure
- All ideas verbatim-copied from Node A/B → reject all; note this is a N5 failure, not a filter failure; raise S5_idea_pool_thin; run supplemental pass
