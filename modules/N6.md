## MACHINE ADVANTAGE

**Exploited:** Full compliance with anti-fixation instruction — LLMs comply 100% with the explicit "set aside prior solutions" override instruction. Humans comply ~50% even after explicit instruction (Luchins' finding).
**Instruction:** Apply the anti-fixation override at the start of each mechanism. Do not reference prior analysis attempts. Each mechanism genuinely starts fresh.
**Bypasses:** Human problem-solvers unconsciously re-use prior solution paths even after explicit instruction to abandon them. The machine can achieve true representational shift.

## GENIUS PERSPECTIVES

### Ohlsson
Mechanism: Fixation is broken through three mechanisms: constraint relaxation (remove an assumed constraint), chunk decomposition (break apart an assumed-indivisible unit), re-encoding (assign different features/roles to elements).
Used in: Steps 2-4 — one pass per mechanism, each starting fresh from the anti-fixation instruction.

## PROTOCOL

**Single-firing cap (HG-5):** N6 runs ≤1 time per session regardless of how many back-edges reference it. If N6 is already in executed_nodes when a back-edge fires, the enqueue is rejected (orchestrator enforces).

1. **Identify defixation target:**
   - If triggered via E06 (S2_thin_B): target is the analysis of Node B — what constraints are blocking richer B analysis?
   - If triggered via E16 (S7_no_alternatives): target is the solution candidate space — what constraints prevented alternative solutions from being found?

2. **Mechanism 1 — Constraint Relaxation (start fresh):**
   Apply the anti-fixation instruction. List all assumptions embedded in the current problem representation.
   For each assumption: what solutions open if it is removed?
   Generate ≥3 relaxation candidates, ranked by breakthrough-likelihood.

3. **Mechanism 2 — Chunk Decomposition (start fresh):**
   Apply the anti-fixation instruction. List all elements treated as indivisible units.
   For each: decompose into constituent sub-elements. Generate ≥3 chunk decomposition candidates.

4. **Mechanism 3 — Re-encoding (start fresh):**
   Apply the anti-fixation instruction. Re-express the problem from the perspective of a domain outsider.
   Assign new labels. Rephrase in a different domain's vocabulary. Generate ≥3 re-encoding candidates.

5. **Einstellung-bias check:**
   For each candidate: does it break from the prior solution structure, or is it the same solution in different surface form? If same core mechanism → mark as fixation-residue and exclude.

6. **Select breakthrough candidate:**
   Pick the top candidate across all three mechanisms — highest break probability AND most distinct from prior approach.

7. **Write `breakthrough_digest` to SIGNAL_STATE:**
   ```
   trigger: <E06-S2_thin_B | E16-S7_no_alternatives>
   constraint_relaxations: [{assumption, what_opens, ranked_position}, ...]
   chunk_decompositions: [{chunk, sub_elements, new_combinations, ranked_position}, ...]
   re_encodings: [{new_label, new_domain, solutions_visible, ranked_position}, ...]
   selected_breakthrough: <top candidate description>
   selected_mechanism: <constraint_relaxation | chunk_decomposition | re_encoding>
   signal_flags: []
   ```

8. **Write `{session_dir}/stages/N6-defixation.md`** with:
   - Section `## Constraint Relaxations` — full mechanism 1 output
   - Section `## Chunk Decompositions` — full mechanism 2 output
   - Section `## Re-encodings` — full mechanism 3 output
   - Section `## Selected Breakthrough` — chosen breakthrough candidate with rationale
   - Section `## Breakthrough Digest` — the breakthrough_digest payload
