## MACHINE ADVANTAGE

**Exploited:** Systematic adversarial coverage without effort asymmetry — Popper's falsification requires equal skepticism toward all hypotheses. The machine applies the same falsification intensity to every idea candidate without the human tendency to apply less skepticism to ideas the reasoner generated.
**Instruction:** Apply ALL THREE falsification checklists to ALL solution candidates. Do not shortcut based on the quality of the idea. Apply equal skepticism regardless of how strong the idea seems.
**Bypasses:** Human adversarial reviewers apply more skepticism to ideas they dislike and less to ideas they find appealing (Millikan bias). The machine applies constant skepticism.

## GENIUS PERSPECTIVES

### Popper
Mechanism: Scientific knowledge advances only through falsification attempts. An unfalsified hypothesis is not confirmed — it is just not yet challenged. The job of adversarial verification is to challenge every idea as hard as possible.
Used in: Steps 2-4 — apply all three falsification checklists systematically, looking for the specific counter-example that would break each idea.

### Millikan
Mechanism: Detect differential effort applied to confirming vs. disconfirming evidence. Flag when the reasoning works harder to support a claim than to refute its alternatives.
Used in: Step 5 — Millikan test for each solution candidate: was equal effort applied to finding counter-evidence?

## PROTOCOL (for subagent — N7 is a spawn)

1. **Load all solution candidates:**
   From ideas_digest: extract the `ideas` list.
   If breakthrough_digest is available: also include breakthrough ideas as additional candidates.
   Total candidate pool: all ideas + any breakthrough candidates.

2. **Extreme Scenario Testing (Checklist 1 from falsification-checklists.md):**
   For each candidate idea:
   - Test at boundary regimes: parameter→0, parameter→∞, edge cases
   - Record: `{idea_id, scenario, result: holds|fails|degenerate|undefined, failure_scope}`
   - Note counter-examples (specific cases where the idea fails)

3. **Millikan Test (Checklist 2):**
   For each candidate:
   - Inventory effort applied to finding evidence against vs. for the idea
   - Flag asymmetry: if finding counter-evidence required much less effort → mark `asymmetry: YES`

4. **Darwin's Golden Rule — Active Disconfirming-Evidence Search (Checklist 3):**
   For each candidate:
   - Actively search for: known counter-examples, classes of problems where it fails, theoretical objections, mechanism gaps
   - Produce density report: `{disconfirming_count, counter_examples, failure_classes, strongest_objection, weakest_link}`
   - Apply LOW-DENSITY WARNING if fewer than 3 disconfirming items found

5. **Cargo-Cult Scan:**
   Check all falsification steps for cargo-cult patterns (assertions without concrete referents, vague scope claims, etc.). Flag and replace with genuine falsification or mark `[UNFALSIFIED]`.

6. **Signal evaluation — S7_no_alternatives:**
   Raise `S7_no_alternatives` if: ALL candidate ideas survive all three checklists with NO counter-examples found (density=0 across all candidates). This is the signal that there are genuinely no alternatives identified — defixation needed.
   Include `"S7_no_alternatives"` in `falsification_result.signal_flags` if raised.

7. **Write `falsification_result` digest to SIGNAL_STATE:**
   ```
   candidates_tested: <N>
   candidates_with_counter_examples: <N>
   candidates_surviving_all_checks: <N>
   top_vulnerabilities: [{idea_id, vulnerability, counter_example}, ...]
   signal_flags: [S7_no_alternatives] or []
   ```

8. **Write `adversarial_digest` to SIGNAL_STATE:**
   ```
   per_candidate_results: [{idea_id, extreme_scenario_result, millikan_asymmetry, density_score, survivability}, ...]
   overall_adversarial_verdict: <strong|moderate|weak|none>
   cargo_cult_flags: [...]
   signal_flags: []
   ```

9. **Write `{session_dir}/stages/N7-adversarial-verify.md`** with:
   - Section `## Falsification Tests` — per-candidate checklist results
   - Section `## Counter-examples` — concrete counter-examples found
   - Section `## Falsification Result` — falsification_result payload
   - Section `## Adversarial Digest` — adversarial_digest payload
   - Section `## Signal Flags` — `S7_no_alternatives: RAISED` or `NOT RAISED` with rationale
