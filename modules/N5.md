## MACHINE ADVANTAGE

**Exploited:** Parallel domain scanning without domain-expertise fatigue — the machine can scan all 25 domains in the catalog in a single pass, applying each domain's structural class to the problem without the fatigue-driven shortcuts a human domain expert takes.
**Instruction:** Scan all 25 domains in domain-catalog.md for structural class matches. Do not stop after finding the first good match. Apply de Bono techniques when domain scanning yields <3 viable ideas.
**Bypasses:** Human lateral thinkers anchor on familiar domains. The machine scans the full catalog without anchoring bias.

## GENIUS PERSPECTIVES

### de Bono
Mechanism: Lateral thinking escapes the dominant logic sequence by deliberately moving sideways to new starting points. The goal is not to find the "right" domain but to find a domain that reframes the problem.
Used in: Domain passes — for each xref entry, ask "what domain has solved a structurally similar problem?" Then extract the domain solution pattern, not the surface details.

## PROTOCOL (for subagent — N5 is a spawn)

**Bounded iteration (HG-5):** ≤3 domain passes, ≤50 ideas total.

1. **Load xref_map** from the inlined predecessor digest. Extract the list of xref entries (B-finding → A-section → action).

2. **Domain Pass 1 — Structural Class Matching:**
   Express the binding constraint from each high-relevance xref entry in domain-agnostic terms.
   Scan all 25 domains in domain-catalog.md for structural class match.
   For each match: generate 1-3 lateral ideas by applying the domain's known solution patterns to the xref entry.
   Cap: ≤25 ideas from Pass 1.

3. **Domain Pass 2 — de Bono Techniques:**
   If Pass 1 yielded <10 ideas OR ideas feel constrained: apply de Bono techniques from debono-techniques.md.
   Apply Provocation, Random Entry, and Reversal across the top 5 xref entries.
   Generate ≤15 additional ideas.

4. **Domain Pass 3 — Gap-Driven Ideation:**
   Review A1's `## Gaps` section (from intake_digest or N2 analysis_digest).
   For each gap not yet addressed by any xref entry: generate 1-2 ideas directly targeting the gap.
   Cap: ≤10 additional ideas.

5. **Dedup and tag:**
   Collapse near-duplicate ideas: same (source_xref_entry, normalized_idea) → keep first occurrence.
   Tag each idea: `{idea_id, source_xref_id, domain_source, idea_text, structural_justification}`.
   Total: ≤50 ideas.

6. **Write `ideas_digest` to SIGNAL_STATE:**
   ```
   ideas_total: <N>
   pass_counts: {pass1: N, pass2: N, pass3: N}
   stop_reason: <pass-cap | idea-cap | no-new-ideas>
   ideas: [{idea_id, source_xref_id, domain_source, idea_text, structural_justification}, ...]
   signal_flags: []
   ```

7. **Write `{session_dir}/stages/N5-lateral-ideate.md`** with:
   - Section `## Domain Passes` — per-pass output with domain mappings and idea generation
   - Section `## Lateral Ideas (<=50)` — final deduplicated idea list
   - Section `## Ideas Digest` — the ideas_digest payload
