**Non-overwrite guarantee (HG-1, HG-4):** Never write to Node A's source path. All output goes to `{session_dir}/enhanced.md`. This file is NEW — never an in-place modification of Node A.

1. **Load accepted solutions from solution-catalog.md:**
   Filter to ACCEPT and ACCEPT-CONDITIONAL entries only. Reject entries are ignored.

2. **Load A1 constraints as the no-regression reference:**
   From N2's A1 analysis, extract all constraints listed in `## Constraints` section. This is the complete constraint set that must survive integration.

3. **If DEEP mode and expansion_digest available:** incorporate expanded/deepened content from N12 into the solution set.

4. **Integration order:**
   Apply solutions in this precedence:
   - First: solutions whose source traces to Headline Insight (from N3's tailored_B1 if available)

   - For solutions targeting the same A-section: apply in sequence; compose if compatible; log conflict if contradictory

5. **Conflict resolution (two solutions targeting the same A-section):**
   - Both compatible: compose — apply both in sequence, verify composed result
   - Contradictory: apply higher-utility solution; log conflict to Enhancement Summary
   - Equal utility: apply lower id (stable sort)
