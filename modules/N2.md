## MACHINE ADVANTAGE

**Exploited:** Sub-subagent internal parallelism — DualAnalyze fans out to two sub-subagents (A1 and B1) within this Agent context, running both analyses in parallel. This halves the analysis wall-clock time compared to sequential A→B processing.
**Instruction:** Immediately after loading context, dispatch two parallel sub-subagent calls — one for A1 structural analysis, one for B1 findings analysis. Do not wait for A1 to complete before starting B1.
**Bypasses:** Sequential pipelines must complete A1 before starting B1. The internal fan-out achieves parallel execution at no additional orchestrator-level spawn cost (this node counts as 1 spawn at the orchestrator level).

## GENIUS PERSPECTIVES

### Tesla
Mechanism: Build a complete mental model of each system before drawing conclusions. Enumerate the full structure of Node A and the full structure of Node B before cross-cutting.
Used in: Steps 1-2 (A1 structural enumeration), ensuring complete coverage before proceeding.

### Darwin
Mechanism: Evidence accumulation — systematic collection of all facts before hypothesis generation. Do not collapse findings prematurely.
Used in: Step 3 (B1 findings extraction) — every section finding is listed individually, not summarized away.

## PROTOCOL (for subagent — N2 is a spawn)

**Internal fan-out instruction:** Immediately dispatch TWO parallel sub-subagent calls within this Agent context. Do not run A1 then B1 sequentially. Both analyses run in parallel; consolidate results when both return.

### Sub-agent A1 prompt template:
```
You are Sub-agent A1 for DualAnalyze. Read Node A from {session_dir}/input-a.md.
Produce a structural decomposition with these mandatory sections:
1. Intent — What Node A is trying to accomplish, its purpose and goals
2. Structure — Section breakdown, heading hierarchy, organizational flow
3. Key Claims — Explicit assertions stated in Node A (one bullet per claim)
4. Constraints — Every MUST, MUST-NOT, rule, or invariant Node A imposes (one bullet each)
5. Gaps — Missing information, unstated assumptions, incomplete areas
6. Technical Details — Technical specifics, implementation details, domain content
Return structured output with all 6 sections populated.
```

### Sub-agent B1 prompt template (node_b_type == genius-current or genius-drift):
```
You are Sub-agent B1 for DualAnalyze. Read Node B from {session_dir}/input-b.md.
node_b_type: {node_b_type}
Extract findings from Node B by enumerating what each section contains.
For genius-current: cover all 10 canonical sections in the order they appear.
For genius-drift: cover matched sections via map, scan unmatched sections generically.
For each section finding: tag with source_section, confidence level, and action potential.
Return a flat findings list ordered by section.
```

### Sub-agent B1 prompt template (node_b_type == generic-fallback):
```
You are Sub-agent B1 for DualAnalyze. Read Node B from {session_dir}/input-b.md.
node_b_type: generic-fallback
Run a single generic extraction pass over the full document.
Produce a flat findings list: each finding tagged with best-guess source_section
(use heading it falls under, or "generic" if no heading).
Return all findings — do not collapse or summarize.
```

1. **Dispatch both sub-subagents in parallel.** Fire A1 and B1 simultaneously.

2. **Wait for both returns.** Consolidate A1 and B1 outputs.

3. **Signal evaluation — S2_thin_B:**
   Raise `S2_thin_B` signal if ANY of:
   - `node_b_type == "generic-fallback"`
   - `node_b_type == "inline-substitute"`
   - Fewer than 3 canonical genius sections found in Node B (count from intake_digest.matched_sections)
   Include `"S2_thin_B"` in `analysis_digest.signal_flags` if raised.

4. **Write `analysis_digest` to SIGNAL_STATE:**
   ```
   a1_summary: <structured A1 summary: intent, structure, key claims, constraints, gaps>
   b1_summary: <structured B1 summary: findings by section or flat list>
   node_b_type: <from intake_digest>
   signal_flags: [S2_thin_B] or []
   a1_section_count: <integer>
   b1_finding_count: <integer>
   ```

5. **Write `{session_dir}/stages/N2-dual-analyze.md`** with:
   - Section `## A1 Structural Analysis` — full A1 output (all 6 sub-sections)
   - Section `## B1 Findings Analysis` — full B1 output (section-by-section or flat list)
   - Section `## Analysis Digest` — the analysis_digest payload
   - Section `## Signal Flags` — `S2_thin_B: RAISED` or `S2_thin_B: NOT RAISED` with rationale
