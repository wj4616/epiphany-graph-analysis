**Exploited:** Simultaneous multi-document analysis — enumeration of both Node A structure and Node B section inventory in a single parallel pass without sequential bottleneck.
**Instruction:** Process Node A and Node B simultaneously. Enumerate Node A primitives and Node B section headers in parallel. Mark node_b_type from genius detection before any downstream signals are evaluated.

## PROTOCOL

1. **HG-1 verification (must be first):**
   Check that `{session_dir}/enhanced.md` ≠ the source path of Node A. If the same file would be overwritten, HALT with error: "HG-1 violation: enhanced.md target equals Node A source path. Aborting."

3. **Read Node B from `{session_dir}/input-b.md`.**

4. **Genius Detection on Node B:**
   Count canonical-or-synonym section headers present. Use the table:

   | Canonical Header | Accepted Synonyms |

   - ≥8 canonical-or-synonym headers → `node_b_type = "genius-current"`
