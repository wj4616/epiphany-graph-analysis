## MACHINE ADVANTAGE

**Exploited:** Systematic thin-spot identification across all sections simultaneously — the machine can scan the entire enhanced.md for relative depth variance without the cognitive load that limits human reviewers to checking a few sections.
**Instruction:** Enumerate ALL sections of enhanced.md. Rate each section's depth on a 3-point scale (shallow/adequate/deep). Flag all shallow sections as thin spots.
**Bypasses:** Human reviewers identify thin spots through subjective impression. The machine applies a consistent depth metric across all sections.

## GENIUS PERSPECTIVES

### Feynman
Mechanism: The second-pass test — "If I explained this section to a 12-year-old, what would they still not understand?" Thin spots are sections where key reasoning is implicit or hand-waved. The expansion pass makes them explicit.
Used in: Step 2 — for each thin spot, ask what the section assumes the reader knows. If the assumption is non-trivial, it should be made explicit.

## PROTOCOL

**Bounded iteration (HG-5):** N12 runs ≤1 time per session. N10 re-runs ≤1 time after N12. No further back-edge to N12.

1. **Confirm activation conditions:**
   - DEEP mode: must be true
   - S11_artifact_gap in verification_report.signal_flags: must be true
   - If either condition is false: write diagnostic note and exit without producing expansion_digest.

2. **Identify thin spots from self-audit:**
   Read R6 detail in self-audit.md. Identify which artifacts are pending/missing.
   Read enhanced.md — scan all sections for relative depth:
   - Shallow: section makes a claim but does not explain it or provide supporting detail
   - Adequate: section explains its claim with one supporting point
   - Deep: section explains claim with multiple supporting points and anticipates objections
   List all SHALLOW sections as thin spots.

3. **Second-pass deepening (one pass only — HG-5):**
   For each thin spot:
   a. Identify the implicit assumption or unexplained claim
   b. Draft the explicit explanation (2-4 sentences)
   c. Verify the expansion does not contradict any constraint from A1
   d. Tag: `{section, thin_reason, expansion_text, constraint_check: PASS|FAIL}`
   Drop any expansion where constraint_check = FAIL.

4. **If no improvements found:**
   Write expansion_digest with `improvements_found: false` and a diagnostic note.
   Do NOT force-create content to fill space.

5. **Write `expansion_digest` to SIGNAL_STATE:**
   ```
   thin_spots_found: <N>
   expansions_generated: <N>
   improvements_found: true|false
   expansions: [{section, thin_reason, expansion_text, constraint_check}, ...]
   diagnostic_note: <only if no improvements found>
   signal_flags: []
   ```

6. **Write `{session_dir}/stages/N12-expand.md`** with:
   - Section `## Thin Spots Identified` — all shallow sections with thin_reason
   - Section `## Second-Pass Deepening` — per-thin-spot expansion record
   - Section `## Expansion Digest` — the expansion_digest payload
